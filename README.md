# OpsPilot

OpsPilot is an AI-powered IT incident investigation and resolution platform.

## Current Status

🚧 Early development

The project is being built incrementally from a basic FastAPI service into an agentic AI system capable of investigating incidents using logs, metrics, historical incidents, and operational runbooks.

## Current Features

- FastAPI backend
- Incident submission API
- Automatic API documentation with Swagger
- Pydantic request validation

## Planned Features

- Incident investigation workflow
- Historical incident knowledge base
- RAG-based troubleshooting
- AI-powered root cause analysis
- Agentic workflow orchestration
- Tool calling
- Human-in-the-loop remediation
- Evaluation framework
- Observability
- Docker deployment

## Tech Stack

- Python
- FastAPI
- Uvicorn
- Git
- GitHub

## Project Goal

Build a production-style AI operations assistant that can investigate IT incidents, identify probable root causes, recommend remediation actions, and provide evidence-backed explanations.
